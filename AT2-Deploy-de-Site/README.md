📝 Descrição do Projeto
Este projeto consiste no desenvolvimento de um site web informativo e interativo dedicado ao Telescópio Espacial James Webb (JWST). Nele, é possível explorar as maravilhas do cosmos, suas descobertas revolucionárias e imagens espaciais impressionantes.

🚀 Tecnologias Utilizadas
Linguagem: HTML5, CSS e JavaScript

Ferramentas: VSCode, GitHub Pages

Autores: Bruno Gabriel e Alex Sander

📊 Resultados e Aprendizados
O projeto alcançou um funcionamento fluido e responsivo, entregando uma interface rica em conteúdo astronômico e navegação organizada por páginas.

Estruturação Multitelas: Organização de seções como Início, Sobre, Descobertas, Galeria e Comparação para uma experiência de navegação completa.

Interatividade: Implementação de recursos visuais dinâmicos para a galeria e carregamento de imagens em alta resolução.

🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial estritamente como ferramenta de suporte tecnológico para estruturação e refinamento do código. Todo o conteúdo gerado foi revisado, testado e compreendido por nós, garantindo a nossa responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
