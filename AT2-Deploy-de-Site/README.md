
# 🌌 Explorando o Universo — Telescópio Espacial James Webb

### 📖 Desenvolvimento de Páginas Web com HTML5

Este projeto consiste no desenvolvimento de um site informativo e interativo dedicado ao **Telescópio Espacial James Webb (JWST)**, um dos maiores avanços da exploração espacial.

O site permite explorar as maravilhas do cosmos, conhecer descobertas astronômicas e visualizar imagens impressionantes do universo, proporcionando uma experiência de navegação organizada e acessível.

---

## 🚀 Tecnologias Utilizadas

As seguintes tecnologias e ferramentas foram utilizadas no desenvolvimento do projeto:

### 💻 Linguagens
- **HTML5:** Estruturação e organização do conteúdo das páginas.
- **CSS3:** Estilização e apresentação visual do site.
- **JavaScript:** Implementação de funcionalidades interativas.

### 🛠️ Ferramentas
- **Visual Studio Code:** Ambiente de desenvolvimento.
- **GitHub:** Armazenamento e versionamento do código.
- **GitHub Pages:** Publicação e hospedagem do site.

---

## 📂 Estrutura e Funcionalidades

O site foi organizado em cinco seções principais:

| Página | Descrição |
| :--- | :--- |
| 🏠 **Início** | Apresentação do Telescópio James Webb e introdução ao conteúdo. |
| 🔭 **Sobre** | Informações sobre o telescópio, sua história e seus objetivos. |
| 🌠 **Descobertas** | Apresentação de descobertas e observações realizadas pelo JWST. |
| 🖼️ **Galeria** | Exibição de imagens espaciais e registros astronômicos. |
| 🌍 **Comparação** | Conteúdo comparativo para facilitar a compreensão das informações apresentadas. |
