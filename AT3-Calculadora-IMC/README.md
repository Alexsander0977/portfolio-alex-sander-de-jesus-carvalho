
# 🧮 Calculadora de IMC — Índice de Massa Corporal

### 📖 Descrição do Projeto

Este projeto consiste no desenvolvimento de uma aplicação web para o cálculo do **Índice de Massa Corporal (IMC)**, permitindo que os usuários obtenham uma estimativa de sua classificação de peso com base na altura e no peso informados.

A aplicação foi desenvolvida com o objetivo de oferecer uma ferramenta simples, intuitiva e acessível, utilizando tecnologias de desenvolvimento Front-End.

Por meio de uma interface organizada e responsiva, o usuário pode inserir suas informações, realizar o cálculo e visualizar o resultado acompanhado de sua respectiva classificação.

---

## 📐 Lógica de Funcionamento

O cálculo do Índice de Massa Corporal é realizado por meio da seguinte fórmula:

**IMC = Peso (kg) / Altura² (m)**

Após o preenchimento dos campos, o JavaScript realiza o cálculo e apresenta o resultado ao usuário.

### 📊 Classificação do IMC para Adultos

| Resultado do IMC | Classificação |
| :--- | :--- |
| Abaixo de 18,5 | Abaixo do peso |
| 18,5 a 24,9 | Peso adequado |
| 25,0 a 29,9 | Sobrepeso |
| 30,0 a 34,9 | Obesidade Grau I |
| 35,0 a 39,9 | Obesidade Grau II |
| 40,0 ou mais | Obesidade Grau III |

**Observação:** O IMC é um indicador geral e não substitui uma avaliação individual realizada por um profissional de saúde.
