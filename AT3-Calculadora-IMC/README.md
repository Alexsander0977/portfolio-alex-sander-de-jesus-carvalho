🎬 Calculadora IMC
📝 Descrição do Projeto
Este projeto consiste no desenvolvimento de uma aplicação web de Calculadora de IMC (Índice de Massa Corporal). Nela, é possível calcular e identificar se o peso está ideal para a altura informada.

🚀 Tecnologias Utilizadas
Linguagem: HTML5, CSS e JavaScript

Bibliotecas: Bootstrap

Ferramentas: VSCode

Modelo de IA: Gemini

📊 Resultados e Aprendizados
O projeto alcançou um funcionamento estável e responsivo em ambiente de testes, entregando uma interface limpa e intuitiva para os usuários.

Interface Responsiva: Implementação bem-sucedida de componentes e do sistema de grid do Bootstrap para garantir compatibilidade com diferentes tamanhos de tela.

Lógica em JavaScript: Aprimoramento da manipulação do DOM e estruturação de funções matemáticas para o cálculo preciso do IMC e categorização dos resultados.

🧠 Declaração de Uso Ético da IA
Este projeto utilizou a inteligência artificial Gemini estritamente como ferramenta de suporte tecnológico para a estruturação inicial do código. Todo o conteúdo gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, a integridade e o funcionamento da aplicação.
