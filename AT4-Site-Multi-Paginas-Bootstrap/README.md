
# 🎮 História dos Videogames — Site Multi-Páginas com Bootstrap

### 📖 Descrição do Projeto

Este projeto consiste no desenvolvimento de um **site multi-páginas responsivo**, dedicado à história e à evolução dos jogos eletrônicos, dos consoles e da indústria dos videogames.

O site apresenta informações sobre diferentes gerações de consoles, franquias marcantes, avanços tecnológicos e curiosidades sobre o universo dos jogos eletrônicos.

O objetivo é proporcionar uma experiência informativa e visualmente atrativa, utilizando tecnologias de desenvolvimento Front-End e recursos do Bootstrap para garantir uma navegação organizada, intuitiva e responsiva.

## 📂 Estrutura do Site

O projeto foi organizado em cinco páginas principais, oferecendo uma navegação completa pelos conteúdos relacionados à história dos videogames.

| Página | Descrição |
| :--- | :--- |
| 🏠 **Início** | Apresentação do projeto e introdução à história dos videogames. |
| 🕹️ **Sobre** | Informações sobre a origem, evolução e importância dos jogos eletrônicos. |
| 🖼️ **Galeria** | Exibição de imagens e conteúdos relacionados a consoles, jogos e franquias históricas. |
| 💡 **Curiosidades** | Informações e fatos interessantes sobre a indústria dos videogames. |
| 📩 **Contato** | Página destinada à comunicação por meio de um formulário de contato. |
