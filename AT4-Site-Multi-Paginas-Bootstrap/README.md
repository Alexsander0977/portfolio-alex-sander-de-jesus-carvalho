📝 Descrição do Projeto
Este projeto consiste no desenvolvimento de um site multi-páginas responsivo estruturado para contar a evolução dos jogos eletrônicos, consoles e curiosidades sobre a indústria que conquistou o mundo. O projeto conta com páginas dedicadas como Início, Sobre, Galeria, Curiosidades e Contato.

🚀 Tecnologias Utilizadas
Linguagem: HTML5, CSS e JavaScript

Bibliotecas: Bootstrap

Ferramentas: VSCode, GitHub Pages

Modelo de IA: Gemini

📊 Resultados e Aprendizados
O projeto alcançou um funcionamento estável, responsivo e com navegação multi-páginas fluida, entregando uma experiência visual rica com imagens de consoles históricos e blocos informativos organizados.

Estruturação Multi-Páginas: Organização de um sistema de navegação coeso integrando diversas seções temáticas (Início, Sobre, Galeria, Curiosidades e Contato).

Design Responsivo com Bootstrap: Aplicação de componentes e classes do Bootstrap para garantir compatibilidade e um layout moderno em diferentes tamanhos de tela.

🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial Gemini estritamente como ferramenta de suporte tecnológico para estruturação inicial do código. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
